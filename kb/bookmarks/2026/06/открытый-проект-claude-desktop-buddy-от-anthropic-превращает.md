# Открытый проект Claude Desktop Buddy от Anthropic превращает устройства на ESP32-S3 в интерактивных настольных AI-компаньонов &#8212; CNXSoft- новости Android-приставок и встраиваемых систем

> URL: https://share.google/qOt8E3vDB9KyciVjw

## Summary
Anthropic открыла проект Claude Desktop Buddy — эталонное аппаратное устройство-компаньон на ESP32-S3 (M5StickC Plus), которое подключается к десктопному приложению Claude через BLE. Устройство позволяет одобрять/отклонять запросы физическими кнопками, отображает состояние AI-агента в стиле Тамагочи и поддерживает кастомные GIF-персонажи. Исходный код опубликован на GitHub.

## Key Points
- Anthropic открыла Bluetooth API (Claude Hardware Interface) для подключения железа к десктопному Claude
- Эталонный проект Claude Desktop Buddy работает на M5StickC Plus ($30) с ESP32-S3
- Функция начиналась как ASCII-пасхалка в Claude Code CLI 1 апреля 2026
- Физические кнопки для одобрения/отклонения запросов без возврата к экрану
- 7 состояний анимации: сон, ожидание, занят, внимание, празднование, головокружение, сердце
- Поддержка кастомных GIF-персонажей (до 1,8 МБ) через drag-and-drop
- Проект построен на Arduino + PlatformIO, также доступен ESP-IDF SDK от Espressif
- Взаимодействие локальное, без API-ключей и интернета
- Отличается от сообщественного Clawdmeter — это официальный проект Anthropic
