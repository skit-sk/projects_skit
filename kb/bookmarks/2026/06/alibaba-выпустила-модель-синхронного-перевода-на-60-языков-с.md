# Alibaba выпустила модель синхронного перевода на 60 языков с задержкой 2,8 секунды - Инк.

> URL: https://share.google/ifeBDVGtu18Kx9WAf

## Summary
Alibaba (команда Qwen) выпустила модель синхронного перевода Qwen3.5-LiveTranslate-Flash с задержкой 2,8 секунды, поддержкой 60 языков на входе и 29 на выходе, мультимодальным анализом видео и функцией имитации голоса.

## Key Points
- Модель Qwen3.5-LiveTranslate-Flash поддерживает 60 языков на входе и 29 на выходе
- Задержка перевода составляет 2,8 секунды
- Модель мультимодальна: анализирует видео параллельно со звуком (движения губ, жесты, текст на экране)
- Использует механизм reading unit processing для перевода до завершения фразы
- Точность более 94% по сравнению с переводом не в реальном времени
- Функция имитации голоса: переведённая речь воспроизводится с тембром и интонацией оригинала
- Динамическая работа с глоссариями для отраслевой терминологии
- Модель доступна через Alibaba Cloud Model Studio по WebSocket
