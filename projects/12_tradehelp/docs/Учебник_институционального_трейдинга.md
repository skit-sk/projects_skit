# Часть I: Учебник

## Глава 1: Введение — от индикаторов к микроструктуре

### 1.1 Эпистемологический поворот

Современная аналитическая парадигма требует четкого разделения между лаггирующими (запаздывающими) индикаторами и микроструктурными инструментами реального времени.

**Классификация:**

| Класс | Примеры | Математическое свойство | Идеальное состояние рынка |
|-------|---------|------------------------|---------------------------|
| Trend Following | MACD | Разница EMA₁₂ и EMA₂₆ | Трендовая фаза (ADX > 30) |
| Momentum | RSI, Stochastic | Процентные границы (0-100) | Боковое движение (ADX < 30) |
| Volatility | Bollinger Bands | Стандартное отклонение | Циклы сжатия/расширения |
| Микроструктура | Order Flow | Реальный баланс лимитных/рыночных ордеров | Любое состояние рынка |

**Математическая избыточность:** Использование инструментов одного класса (например, RSI и Stochastic) не даёт нового измерения анализа.

### 1.2 ADX-фильтр

ADX (Average Directional Index) — ключевой фильтр состояния рынка:

- **ADX < 30** — состояние равновесия (mean reversion). Применяются осцилляторы, стратегии отскока от границ Bollinger Bands.
- **ADX > 30** — трендовая фаза. Применяются MACD, SMC (BOS/CHoCH), Volume Profile.

### 1.3 Иерархия подтверждений

Институциональный анализ строится по иерархии:
1. **Макро-фаза** (Wyckoff) — накопление/распределение
2. **Структура** (SMC) — сломы, POI, ликвидность
3. **Объём** (Volume Profile) — зоны интереса
4. **Поток ордеров** (Order Flow) — микроструктурное подтверждение
5. **Деривативы** (OI, Funding) — здоровье позиций

## Глава 2: Классические индикаторы

### 2.1 MACD (Moving Average Convergence Divergence)

**Формула:**
```
MACD Line = EMA₁₂(C) − EMA₂₆(C)
Signal Line = EMA₉(MACD Line)
MACD Histogram = MACD Line − Signal Line
```

**Применение:**
- Пересечение MACD и Signal = сигнал
- Гистограмма = ускорение/замедление тренда
- Дивергенция: цена ↑, MACD ↓ = ослабление тренда

### 2.2 Стохастический осциллятор (Stochastic)

**Формула:**
```
%K = ((C − L₁₄) / (H₁₄ − L₁₄)) × 100
%D = SMA₃(%K)
```

**Применение:**
- %K > 80 = перекупленность, %K < 20 = перепроданность
- Пересечение %K и %D
- Дивергенция

### 2.3 RSI (Relative Strength Index)

**Формула:**
```
RSI = 100 − (100 / (1 + RS))
RS = Average Gain / Average Loss (за 14 периодов)
```

**Применение:**
- RSI > 70 = перекупленность, RSI < 30 = перепроданность
- Дивергенции (regular / hidden)

### 2.4 VWAP (Volume-Weighted Average Price)

**Формула:**
```
VWAP = Σ(Pᵢ × Vᵢ) / ΣVᵢ
```
где Pᵢ — цена транзакции, Vᵢ — объём транзакции.

**Применение:**
- Anchored VWAP — закреплён на значимом экстремуме
- Цена выше VWAP = бычий уклон, ниже = медвежий
- Отскок от VWAP = институциональная поддержка

## Глава 3: Индикаторы волатильности

### 3.1 ATR (Average True Range)

**Формула:**
```
True Range = max(H − L, |H − C_prev|, |L − C_prev|)
ATR(14) = EMA₁₄(TR)
```

**Применение:**
- Фильтр Displacement: тело свечи > 1.5 × ATR(14) = валидный MSS
- DynamicStep = ATR(14) × 0.2 (шаг гистограммы Volume Profile)
- Стоп-лосс: 1.5–2 × ATR от точки входа

### 3.2 Bollinger Bands

**Формула:**
```
Middle = SMA₂₀(C)
Upper = SMA₂₀(C) + 2σ
Lower = SMA₂₀(C) − 2σ
σ = √(Σ(C − SMA₂₀)² / 20)
```

**Применение:**
- Сжатие полос (Squeeze) → предвестник импульса
- Стратегия «Bounce»: отскок от границ при ADX < 30
- Пробой границ при ADX > 30 = усиление тренда

### 3.3 Keltner Channels

**Формула:**
```
Middle = EMA₂₀(C)
Upper = EMA₂₀(C) + ATR(14) × 2
Lower = EMA₂₀(C) − ATR(14) × 2
```

**Применение:**
- Аналог Bollinger, но использует ATR вместо σ
- Пробой внешней границы + ADX > 30 = трендовое движение

### 3.4 Historical Volatility (HV)

**Формула:**
```
HV = σ(ln(Cᵢ / Cᵢ₋₁)) × √252
```
где σ — стандартное отклонение дневных лог-доходностей, 252 — торговых дней в году.

### 3.5 Chaikin Volatility

**Формула:**
```
Chaikin Vol = ((EMA₁₀(H − L) − EMA₁₀(H − L)₋₁) / EMA₁₀(H − L)₋₁) × 100
```

### 3.6 Normalized ATR

**Формула:**
```
NATR = ATR(14) / Close × 100
```

Позволяет сравнивать волатильность активов с разной ценой.

### 3.7 Volatility Ratio (VR)

**Формула:**
```
VR = TR / ATR(14)
```
VR > 3 = экстремальная свеча (возможный разворот)

## Глава 6: Wyckoff — циклы накопления и распределения

### 6.1 Три фундаментальных закона

1. **Закон спроса и предложения:** Цена растёт, когда спрос > предложения. Видим через расширение тел бычьих свечей и рост объёма.
2. **Закон причины и следствия:** Большому движению (следствие) предшествует подготовка (причина) — боковой диапазон.
3. **Закон усилия и результата:** Огромный объём (усилие) без движения цены (результат) = поглощение крупным игроком. Признак разворота.

### 6.2 Фаза накопления (Accumulation) A–E

```
Фаза A: Остановка падения. SC (Selling Climax) — панический объём.
            → AR (Automatic Rally) — автоматический отскок.
Фаза B: Построение причины. Крупный игрок скупает, вытряхивая ритейл
            через ложные пробои границ.
Фаза C (Spring): Решающий момент. Ложный пробой вниз, сбор стопов (SSL),
            быстрый возврат в диапазон. ЛУЧШАЯ ТОЧКА ВХОДА.
            Формула: Price < SC_Low (wick) + Body Close > SC_Low
Фаза D: Подтверждение. SOS (Sign of Strength) — мощные импульсные свечи
            с выходом из диапазона.
Фаза E (Markup): Устойчивый тренд вверх. Откаты — добор позиции.
```

### 6.3 Фаза распределения (Distribution)

Зеркально накоплению:
- **UTAD (Upthrust After Distribution):** Ложный пробой вверх = BSL Sweep
- **LPSY (Last Point of Supply):** Последняя точка предложения перед трендом вниз

### 6.4 Эквивалентность Wyckoff ↔ SMC

| Wyckoff | SMC | Рыночная логика |
|---------|-----|-----------------|
| Spring / Shakeout | SSL Sweep | Захват стопов покупателей под диапазоном |
| Upthrust (UTAD) | BSL Sweep | Захват стопов продавцов над диапазоном |
| SOS (Sign of Strength) | Bullish BOS / MSS | Демонстрация рыночной инициативы |
| LPS (Last Point of Support) | OB Retest / OTE | Последняя точка входа перед трендом |

## Глава 7: Smart Money Concepts (SMC)

### 7.1 Структурные сломы

**BOS (Break of Structure):** Продолжение тренда.
- Close > High(Previous_Swing_High) — бычий
- Close < Low(Previous_Swing_Low) — медвежий
- Объём: стандартный или затухающий

**CHoCH (Change of Character):** Первый сигнал смены тренда.
- Пробой последнего структурного экстремума
- Может быть ложным без подтверждения

**MSS (Market Structure Shift):** Подтверждённый разворот.
- CHoCH + Displacement (тело свечи > 1.5 × ATR(14))
- Всплеск объёма (закон усилия и результата)
- Stacked Imbalances в Footprint в сторону нового тренда

### 7.2 Order Blocks (OB)

**Определение:** Зона аккумуляции/дистрибуции — последняя противоположная свеча перед импульсом.

**Условия валидации:**
1. Наличие displacement (импульсный выход)
2. Создание BOS/CHoCH после OB
3. Является последней противоположной свечой перед импульсом

**Правило:** Цена возвращается к OB для ретеста перед продолжением.

### 7.3 Fair Value Gap (FVG)

**Определение:** Рыночная неэффективность — «прыжок» цены, пропускающий справедливый обмен. Обязательство к возврату.

**Формула:**
```
FVG = Low[i-2] > High[i]  (бычий)
     = High[i-2] < Low[i]  (медвежий)
```

**CE (Consequent Encroachment):** Уровень 50% заполнения FVG. При пробое CE — FVG заполнен.

### 7.4 Breaker vs Mitigation Block

| Параметр | Breaker Block | Mitigation Block |
|----------|---------------|------------------|
| Sweep ликвидности | Обязателен (снятие стопов за экстремумом) | Отсутствует (Failure Swing) |
| Механика | «Двойная ловушка»: стоп-хант пробойщиков и OB-лимитников | Смягчение убыточных позиций институционалов |
| Динамика теста | Агрессивный, взрывной отскок | Упорядоченная коррекция |

## Глава 8: Candle Range Theory (CRT) и циклы AMD

### 8.1 Цикл AMD

Эволюционное продолжение теорий Wyckoff и Ларри Уильямса:

- **Accumulation:** Горизонтальная консолидация. Сбор позиций.
- **Manipulation:** Агрессивный захват ликвидности (Stop Hunt) за границами диапазона. Снятие стопов.
- **Distribution:** Истинное движение к противоположному магниту ликвидности.

### 8.2 Правило трёх свечей CRT

CRT — четвёртая итерация идеи (Wyckoff → Williams → ICT → CRT):

1. **Свеча 1 (Initiation):** Импульсное движение, пробивающее диапазон
2. **Свеча 2 (Misdirection):** FVG-свеча, создающая ловушку
3. **Свеча 3 (Re-entry):** Подтверждает паттерн, закрываясь внутри диапазона Свечи 1

**Валидация:** Если Свеча 3 закрывается вне диапазона Свечи 1 — паттерн невалиден.

## Глава 9: Elliott Wave

### 9.1 Импульсная структура (5-3)

**Импульс (5 волн):** 1-2-3-4-5
**Коррекция (3 волны):** A-B-C

**Кардинальные правила:**
1. Волна 2 никогда не заходит за начало волны 1
2. Волна 3 никогда не бывает самой короткой
3. Волна 4 не перекрывает ценовую зону волны 1 (кроме диагональных треугольников)

### 9.2 Коррекционные паттерны

**Zigzag (5-3-5):**
- Острая коррекция, глубокий откат
- Волна B ≈ 50% волны A
- Волна C ≈ 100–162% волны A

**Regular Flat (3-3-5):**
- Волна B заканчивается у начала A
- Волна C заканчивается у конца A
- Боковая коррекция

**Expanded Flat (3-3-5):**
- Самая коварная ловушка
- **B = 105–138% от A** (пробивает начало A)
- **C = 162% от A** (пробивает конец A)
- Синтез с SMC: C-wave = Phase C (Spring) = SSL Sweep

**Running Flat (3-3-5):**
- Волна C не доходит до конца A
- Признак экстремальной силы основного тренда

**Triangles (3-3-3-3-3):**
- Symmetrical, Ascending, Descending, Expanding
- Обычно в волне 4 перед финальным импульсом

**Сложные коррекции:**
- Double Three: W-X-Y (W = zigzag/flat, X = любая коррекция, Y = zigzag/flat)
- Triple Three: W-X-Y-X-Z

## Глава 10: Volume Profile

### 10.1 Компоненты

| Компонент | Описание |
|-----------|----------|
| **POC (Point of Control)** | Уровень максимального объёма — точка институционального равновесия |
| **Value Area (VA)** | Диапазон 68.2% проторгованного объёма (1 стандартное отклонение) |
| **VAH** | Value Area High |
| **VAL** | Value Area Low |
| **HVN** | High Volume Node — объём > 1.5× среднего |
| **LVN** | Low Volume Node — низкообъёмная зона |

### 10.2 Интерпретация POC

- POC в нижней трети диапазона: бычья аккумуляция
- POC в верхней трети: медвежья дистрибуция
- Множественные POC: фрактальная структура

### 10.3 DynamicStep

**Формула:**
```
Row Size = ATR(14) × 0.2
```

Автоматическая подстройка шага гистограммы под волатильность актива (как в TradingView).

### 10.4 Triple Threat

Слияние трёх факторов для уровня высокого置信:
1. HVN (высокообъёмный узел)
2. Уровень поддержки/сопротивления
3. Anchored VWAP

## Глава 11: Order Flow — поток ордеров и книга заявок

### 11.1 Глубина рынка (DOM / Level 2)

**Bid/Ask Walls:** Крупные лимитные заявки, создающие искусственные стены.

**Order Book Imbalance:**
```
Imbalance = (BidVolume − AskVolume) / (BidVolume + AskVolume)
```
- Imbalance > 0.3 = бычье давление
- Imbalance < -0.3 = медвежье давление

**Bid-Ask Volume Ratio (BAVR):**
```
BAVR = AskVolume / (AskVolume + BidVolume)
```

**Order Book Slope:** Скорость уменьшения объёма от лучшей цены. Крутой slope = мало ликвидности за уровнем.

**Cancel-Replace Velocity:** Скорость отмен/замен заявок. Высокая скорость = спуфинг (фейковые стены).

### 11.2 Лента сделок (Time & Sales)

**Tape Speed:** Количество принтов в секунду.
- Ускорение при подходе к уровню = ритейл-паника
- Slow tape = отсутствие интереса

**Iceberg Orders:**
```
Iceberg = T&S Volume(price L, time T) > 5 × Visible DOM(price L)
при условии Visible Size не уменьшается (мгновенное обновление)
```

**The Axe:** Доминирующий маркет-мейкер или ECN, защищающий сторону стакана. Идентификация «Топора» даёт направленное преимущество.

**Dark Pool Prints:** Внебиржевые блоки с кодами 'D' или 'T' (35-40% объёма США). Кластеры таких принтов = предвестники публичного движения.

### 11.3 Кластерный анализ (Footprint)

**Aggressive Imbalance:**
```
Ask(price) / Bid(price − 1 step) > 3.0 (300%)
```

**Stacked Imbalance:** Три и более последовательных уровней в одной свече с Ask/Bid > 300%.

**Passive Absorption:** Поглощение рыночной агрессии лимитной заявкой, препятствующее расширению свечи. Цена остаётся на месте при высоком объёме.

### 11.4 Delta и CVD

**Delta:**
```
Delta = V(ask) − V(bid)
```
где V(ask) — объём по рыночным покупкам, V(bid) — объём по рыночным продажам.

**CVD (Cumulative Volume Delta):** Накопительная разница Bid/Ask.

**Медвежья дивергенция:** Цена растёт, CVD падает = скрытые продажи лимитами. Институты распределяют позицию.

### 11.5 Онлайн-индикаторы Order Flow

| Индикатор | Формула | Назначение |
|-----------|---------|------------|
| Real-Time CVD | Σ(Buy − Sell) per bar | Накопительная дельта |
| Order Flow Imbalance | (BuyVol − SellVol) / (BuyVol + SellVol) | Давление потока |
| BAVR | Ask / (Ask + Bid) | Перекос книги |
| Tape Speed | Принты/сек | Ритейл-активность |
| DOM Liquidity Heatmap | Bid/Ask объём по ценам | Концентрация лимитников |

## Глава 12: OTE и зоны ликвидности

### 12.1 PD Arrays (Premium vs Discount)

Торговый диапазон делится на зоны:
- **Premium Zone:** Выше 50% диапазона — зона для продаж
- **Discount Zone:** Ниже 50% диапазона — зона для покупок

### 12.2 OTE (Optimal Trade Entry)

**Формула:**
```
OTE = Fib(62%) до Fib(79%) коррекции
Sweet Spot = 70.5%
```

**Расчёт на примере BTC ($60K → $70K):**
- 62% = $63,800
- 79% = $62,100
- Sweet Spot = $62,950

**Институциональная логика:** Вход в OTE обеспечивает наилучшее RR, стоп за 100% (начало импульса).

### 12.3 IRL vs ERL

- **IRL (Internal Range Liquidity):** FVGs и Order Blocks внутри диапазона
- **ERL (External Range Liquidity):** Внешние экстремумы — PDH (Previous Day High), PDL (Previous Day Low)

### 12.4 Магниты ликвидности

**EQH (Equal Highs) / EQL (Equal Lows):**
- Поиск зон, где разница между соседними экстремумами < 0.05% × Price
- Магниты для цены — при подходе ожидается Sweep

**DOL (Draw on Liquidity):** Внешняя ликвидность (PDH/PDL) — главный ценовой магнит, определяющий целесообразность входа.

## Глава 13: Деривативы — OI, фандинг, heatmaps

### 13.1 Open Interest (OI) Trend Health

OI + Price + Funding Rate = полная картина здоровья тренда:

| Цена | OI | Funding | Сигнал | Действие |
|------|----|---------|--------|----------|
| ↑ | ↑ | ~0.01% | Здоровый тренд (приток капитала) | Входим, держим |
| ↑↑ | ↑ | > 0.05% | Leverage Flush (перегрев лонгов) | Стоп, фиксация |
| ↑ | ↓ | — | Затухание (фиксация прибыли китами) | Выход |
| ↓↓ | ↓↓ | — | Капитуляция (массовые ликвидации) | Поиск дна |

### 13.2 Liquidation Heatmaps

**Уровень ликвидации:**
```
Lp (LONG) = Entry × (1 − 1/Leverage)
Lp (SHORT) = Entry × (1 + 1/Leverage)
```

**Пример:** API3 #4: Entry = 0.2992, 10x → Lp = 0.2992 × (1 − 1/10) = 0.2693

**Применение:**
- Агрегация Lp по всем плечам (10x–100x) → heatmap
- Ярко-жёлтые зоны = «магниты» для цены
- Каскады ликвидаций: одна ликвидация → снижение цены → следующая ликвидация

### 13.3 Funding Rate Sentiment

- Funding > 0.05% (положительный): перегрев лонгов, риск смыва
- Funding < −0.05% (отрицательный): избыток шортов, возможный squeeze
- Funding ≈ 0: нейтрально, здоровый тренд

**Funding Drag:** Накопленные комиссии при длительном удержании. При 0.05% каждые 8 часов и 20x плече трейдер теряет 3% маржи в день только на комиссиях.

- **Commercial (Hedgers):** Институциональные хеджеры — «умные деньги»

- **Small Speculators:** Ритейл

### 14.5 Liquidity Sweep как сигнал настроения

- **Sweep ликвидности** = сбор стопов толпы (психологический триггер)
- **Passive Absorption** на уровне = институты забирают ликвидность у паникующего ритейла

```
25. EQH/EQL: |High[i] − High[i-1]| < 0.05% × Price
26. Value Area = 68.2% of total volume (sorted)
27. HVN = Volume > 1.5 × Average Volume
28. Natr = ATR(14) / Close × 100
29. Chaikin Vol = (EMA₁₀(HL) − EMA₁₀(HL)₋₁) / EMA₁₀(HL)₋₁ × 100
30. Historical Volatility = σ(ln(Cᵢ/Cᵢ₋₁)) × √252
31. Put/Call Ratio = Put Volume / Call Volume
32. MVRV = Market Cap / Realized Cap
33. SOPR = Σ(Spent Value in USD) / Σ(Spent Value at Creation in USD)
34. NVT = Network Cap / Daily Transaction Volume
35. Funding Drag = FundingRate × 3 × Days × Leverage
```

## Задача 1: Расчёт OTE для BTC

**Контекст:** Бычий импульс на BTC. Swing Low = $60,000, Swing High = $70,000.

**Задание:** Рассчитайте OTE (62–79%) и Sweet Spot (70.5%).

**Решение:**
```
Диапазон = $70,000 − $60,000 = $10,000
62% отката = $60,000 + $10,000 × (1 − 0.62) = $63,800
79% отката = $60,000 + $10,000 × (1 − 0.79) = $62,100
Sweet Spot (70.5%) = $60,000 + $10,000 × (1 − 0.705) = $62,950
```
