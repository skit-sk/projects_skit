# Глоссарий терминов (100+)

## Базовые (главы 1-5)

| Термин | Определение |
|--------|-------------|
| **Accumulation** | Фаза накопления — институты собирают позицию в диапазоне |
| **ADX** | Average Directional Index — фильтр трендового/бокового рынка |
| **AMD** | Accumulation-Manipulation-Distribution — цикл CRT |
| **ATR** | Average True Range — мера волатильности |
| **BAVR** | Bid-Ask Volume Ratio — перекос книги заявок |
| **BOS** | Break of Structure — пробой структуры (продолжение тренда) |
| **Bollinger Bands** | SMA(20) ± 2σ |
| **Breaker Block** | OB, снятый sweep'ом, меняющий полярность |
| **BSL** | Buy-side Liquidity — ликвидность над хаями (стопы шортов) |
| **CE** | Consequent Encroachment — 50% заполнение FVG |
| **CHoCH** | Change of Character — смена характера рынка |
| **Confluence Score** | 10-факторный скоринг входа (валид ≥ 4) |
| **CVD** | Cumulative Volume Delta — накопительная разница Bid/Ask |
| **CRT** | Candle Range Theory — теория свечного диапазона |
| **Delta** | V(ask) − V(bid) — разница рыночных покупок/продаж |
| **Displacement** | Импульсное движение (тело > 1.5×ATR) |
| **Distribution** | Фаза распределения — институты продают позицию |
| **DOL** | Draw on Liquidity — внешняя ликвидность (PDH/PDL) |
| **DOM** | Depth of Market — книга заявок Level 2 |
| **DXY** | US Dollar Index — индекс доллара США |
| **EQH/EQL** | Equal Highs/Lows — равные экстремумы (магниты) |
| **ERL** | External Range Liquidity — внешние экстремумы |
| **Fear & Greed** | Индекс страха и жадности (0-100) |
| **Footprint** | Кластерный график Bid/Ask по ценам |
| **FVG** | Fair Value Gap — ценовой разрыв (неэффективность) |
| **Funding** | Funding Rate — периодическая комиссия между лонгами/шортами |
| **H&S** | Head & Shoulders — разворотный паттерн |
| **HVN** | High Volume Node — узел высокого объёма |
| **Iceberg** | Скрытая заявка (видима малая часть) |
| **ICT** | Inner Circle Trader — методология (Killzones, AMD) |
| **IRL** | Internal Range Liquidity — FVGs + OB внутри диапазона |
| **Killzone** | Временное окно высокой активности (ICT) |
| **Kelly %** | Оптимальный размер позиции (RR × WR − (1−WR))/RR |
| **LPS** | Last Point of Support — последняя точка поддержки (Wyckoff) |
| **Lp** | Liquidation Price — цена ликвидации |
| **LVN** | Low Volume Node — узел низкого объёма |
| **Mitigation Block** | OB, частично заполненный без sweep'a |
| **MSS** | Market Structure Shift — разворот с displacement |
| **MVRV** | Market Value / Realized Value — on-chain метрика |
| **NVT** | Network Value / Transactions — on-chain метрика |
| **OB** | Order Block — зона институциональных ордеров |
| **OI** | Open Interest — открытый интерес деривативов |
| **OTE** | Optimal Trade Entry — зона Fib 62–79% |
| **PD Array** | Premium/Discount массив — зоны цены |
| **PDH/PDL** | Previous Day High/Low |
| **POC** | Point of Control — уровень макс. объёма |
| **POI** | Point of Interest — ключевой уровень (OB/FVG) |
| **R:R** | Risk/Reward ratio |
| **RSI** | Relative Strength Index — осциллятор 0-100 |
| **SMC** | Smart Money Concepts — концепция умных денег |
| **SOS** | Sign of Strength — признак силы (Wyckoff) |
| **SOPR** | Spent Output Profit Ratio — on-chain метрика |
| **Spring** | Ложный пробой вниз (Wyckoff) |
| **SSL** | Sell-side Liquidity — ликвидность под лоями (стопы лонгов) |
| **Sweep** | Снятие ликвидности (забор стопов) |
| **UTAD** | Upthrust After Distribution — ложный пробой вверх |
| **VA** | Value Area — диапазон 68.2% объёма |
| **VAH/VAL** | Value Area High/Low |
| **VWAP** | Volume-Weighted Average Price |

## Risk Flags (MidasFlow)

| Flag | Условие | Действие |
|------|---------|----------|
| **CRITICAL_RECOVERY** | \|PL\| > Margin | Немедленная активация Recovery |
| **PnL -100%** | Убыток = 100% маржи | Стоп и разбор |
| **PnL -200%** | Убыток = 200% маржи | URGENT |
| **MARGIN_WARNING** | Used > 70% | Снизить leverage |
| **FUNDING_DRAG** | Funding > 0.05%/day | Закрыть позицию |
