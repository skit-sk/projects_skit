# Задачник: 10 задач с решениями

## Задача 1: Расчёт OTE для BTC

**Контекст:** Бычий импульс на BTC. Swing Low = $60,000, Swing High = $70,000.

**Задание:** Рассчитайте OTE (62–79%) и Sweet Spot (70.5%).

**Решение:**
```
Range = $70,000 − $60,000 = $10,000
62% = $60,000 + $10,000 × (1 − 0.62) = $63,800
79% = $60,000 + $10,000 × (1 − 0.79) = $62,100
Sweet Spot (70.5%) = $60,000 + $10,000 × (1 − 0.705) = $62,950
```

## Задача 2: Расчёт ликвидации

**Контекст:** API3 #4, Entry = 0.2992, Leverage = 10x, LONG.

**Задание:** Рассчитайте Lp. На сколько % нужно измениться цене?

**Решение:**
```
Lp = 0.2992 × (1 − 1/10) = 0.2693
Падение до ликвидации: (0.2992 − 0.2693) / 0.2992 × 100 = 10%
```

## Задача 3: Фильтр Displacement

**Контекст:** Цена пробила Swing Low. ATR(14) = 50 pips. Тела пробивающих свечей: 45, 38, 52 pips.

**Задание:** Это истинный MSS или ложный CHoCH?

**Решение:**
```
Threshold = 1.5 × ATR = 1.5 × 50 = 75 pips
Ни одно тело не превышает 75 pips → Displacement НЕ выполнен
→ Это ложный CHoCH, а не MSS
```

## Задача 5: Expanded Flat vs Regular Flat

**Контекст:** Волна A коррекции = 100 пунктов. Волна B пробила начало A и составила 130 пунктов.

**Задание:** Определите тип паттерна. Какова ожидаемая длина C?

**Решение:**
```
B / A = 130 / 100 = 130% → B > 100% A → Expanded Flat
C = 162% × A = 162% × 100 = 162 пункта
```

## Задача 6: Iceberg Detection

**Контекст:** В DOM на уровне $875.00 Ask = 500 акций. За 30 сек лента показывает 12 сделок покупки общим объёмом 8500 акций. После каждого принта Ask обновляется до 500.

**Задание:** Это Iceberg? Обоснуйте.

**Решение:**
```
T&S Vol / DOM Vol = 8500 / 500 = 17 × 5 → Iceberg
Признак: статичный размер DOM при растущем объёме ленты
```

## Задача 7: Order Book Imbalance

**Контекст:** В стакане BTC: Bid объём = 450 BTC, Ask объём = 150 BTC.

**Задание:** Рассчитайте Imbalance. Какое давление?

**Решение:**
```
Imbalance = (450 − 150) / (450 + 150) = 300 / 600 = 0.5
Imbalance > 0.3 → сильное бычье давление
```

## Задача 8: Stacked Imbalance

**Контекст:** В свече на трёх последовательных уровнях:
- Level 1: Ask 1200, Bid 300
- Level 2: Ask 900, Bid 250
- Level 3: Ask 1500, Bid 400

**Задание:** Есть ли Stacked Imbalance?

**Решение:**
```
Level 1: 1200/300 = 4.0 (> 3.0)
Level 2: 900/250 = 3.6 (> 3.0)
Level 3: 1500/400 = 3.75 (> 3.0)
Все три уровня > 300% → Stacked Imbalance подтверждён
```

## Задача 9: Sentiment — Fear & Greed + Funding

**Контекст:** Fear & Greed = 85 (Extreme Greed). Funding = +0.08%. BTC вырос на 30% за месяц.

**Задание:** Каковы риски? Какое действие?

**Решение:**
```

```

## Задача 10: MVRV + SOPR анализ

**Контекст:** MVRV = 0.8. SOPR = 0.95.

**Задание:** Что сигнализируют метрики? Какое действие?

**Решение:**
```
MVRV = 0.8 < 1.0 → актив недооценён (возможное дно)
SOPR = 0.95 < 1.0 → капитуляция (продажа в убыток)
Сигнал: зона накопления (Phase A Wyckoff)
Действие: искать Entry (Spring / OB Retest / OTE)
```
