# Глава 4: Свечные паттерны

## 4.1 Одиночные свечи

| Паттерн | Визуал | Сигнал |
|---------|--------|--------|
| **Doji** | Open ≈ Close | Неопределённость, разворот |
| **Hammer** | Маленькое тело ↑, длинная нижняя тень | Бычий разворот |
| **Hanging Man** | Маленькое тело ↑, длинная нижняя тень | Медвежий разворот |
| **Shooting Star** | Маленькое тело ↓, длинная верхняя тень | Медвежий разворот |
| **Inverted Hammer** | Маленькое тело ↓, длинная верхняя тень | Бычий разворот |
| **Marubozu** | Полное тело, нет теней | Сильный тренд |
| **Spinning Top** | Маленькое тело, тени с обеих сторон | Консолидация |

## 4.2 Двойные паттерны

| Паттерн | Сигнал | Структура |
|---------|--------|-----------|
| **Bullish Engulfing** | ↑ | Бычье тело поглощает предыдущее |
| **Bearish Engulfing** | ↓ | Медвежье тело поглощает предыдущее |
| **Bullish Harami** | ↑ | Маленькое бычье внутри медвежьего |
| **Bearish Harami** | ↓ | Маленькое медвежье внутри бычьего |
| **Piercing Pattern** | ↑ | Медвежья → бычья закрывается > 50% |
| **Dark Cloud Cover** | ↓ | Бычья → медвежья закрывается < 50% |
| **Tweezer Top** | ↓ | Два одинаковых хая |
| **Tweezer Bottom** | ↑ | Два одинаковых лоя |

## 4.3 Тройные паттерны

| Паттерн | Сигнал | Структура |
|---------|--------|-----------|
| **Morning Star** | ↑ | Медвежья → Doji → Бычья |
| **Evening Star** | ↓ | Бычья → Doji → Медвежья |
| **3 White Soldiers** | ↑ | 3 длинных бычьих |
| **3 Black Crows** | ↓ | 3 длинных медвежьих |
| **3 Inside Up** | ↑ | Медвежья→Бычья внутри→Третья выше |
| **3 Inside Down** | ↓ | Бычья→Медвежья внутри→Третья ниже |
| **Tri-Star** | ↑/↓ | 3 Doji подряд |

## 4.4 Паттерны продолжения

- **Rising Three Methods** — бычья + 3 малых медвежьих внутри + бычья
- **Falling Three Methods** — медвежья + 3 малых бычьих внутри + медвежья
- **Upside/Downside Tasuki Gap**

**Правило:** свечной паттерн валиден только на значимом уровне (OB/S/R).
