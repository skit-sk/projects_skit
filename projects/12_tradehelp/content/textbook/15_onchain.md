# Глава 15: On-Chain анализ

## 15.1 Крупные игроки (Whales)

| Метрика | Описание | Сигнал |
|---------|----------|--------|
| **Whale Transaction Count** | Кол-во транзакций > $100k / $1M / $10M за 24ч | Рост = активность китов |
| **Whale Concentration** | % supply в топ-10 адресах | > 30% = централизация риска |
| **Exchange Whale Ratio** | Топ-10 inflow / total inflow | Высокий = киты несут на биржи |
| **Large Tx Volume** | Объём крупных транзакций ($) | Падение = снижение интереса |

## 15.2 Биржевые потоки (Exchange Flows)

| Метрика | Сигнал |
|---------|--------|
| **Exchange Netflow** | Inflow − Outflow. Отрицательный = монеты уходят с бирж (бычий) |
| **Exchange Balance** | Резервы бирж. Падение = дефицит предложения |
| **Stablecoin Inflow/Outflow** | USDT/USDC на биржи = потенциальные покупки (бычий) |
| **BTC/ETH Reserve Risk** | Долгосрочный ценовой индикатор |

## 15.3 Метрики оценки (Valuation)

| Метрика | Формула | Интерпретация |
|---------|---------|---------------|
| **MVRV Ratio** | Market Value / Realized Value | > 3.5 = перегрев, < 1 = дно |
| **SOPR** | Spent Output Profit Ratio | < 1 = капитуляция, > 1 = прибыль |
| **NVT Ratio** | Network Value / Transaction Volume | > 100 = переоценен, < 50 = недооценен |
| **Puell Multiple** | Miner Revenue / 365d MA | < 0.5 = дно майнеров (бычий) |

## 15.4 Сетевая активность

| Метрика | Описание |
|---------|----------|
| **Active Addresses** | Уникальные адреса, участвующие в транзакциях за день |
| **New Addresses** | Новые созданные адреса (рост = adoption) |
| **Average Dormancy** | Средний возраст потраченных монет |
| **CDD (Coin Days Destroyed)** | Кумулятивный показатель долгосрочного движения |
