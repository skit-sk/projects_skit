# Глава 5: Графические паттерны

## 5.1 Разворотные паттерны

| Паттерн | Сигнал | Измерение |
|---------|--------|-----------|
| **Head & Shoulders** | ↓ | Цель = расстояние от головы до линии шеи |
| **Inverse H&S** | ↑ | Перевёрнутый |
| **Double Top** | ↓ | Цель = высота паттерна |
| **Double Bottom** | ↑ | Аналогично |
| **Triple Top** | ↓ | Три уровня сопротивления |
| **Triple Bottom** | ↑ | Три уровня поддержки |
| **Rounding Top** | ↓ | Плавная вершина |
| **Rounding Bottom** | ↑ | Плавное дно |
| **Diamond Top** | ↓ | Расширение + сужение |
| **Diamond Bottom** | ↑ | Аналогично |

## 5.2 Паттерны продолжения

| Паттерн | Описание |
|---------|----------|
| **Bull Flag** | Резкий рост + наклонный канал вниз |
| **Bear Flag** | Резкое падение + наклонный канал вверх |
| **Bull Pennant** | Рост + симметричный треугольник |
| **Bear Pennant** | Падение + симметричный треугольник |
| **Rising Wedge** | Сужающийся диапазон вверх (медвежий) |
| **Falling Wedge** | Сужающийся диапазон вниз (бычий) |
| **Ascending Channel** | Канал вверх (бычий) |
| **Descending Channel** | Канал вниз (медвежий) |
| **Cup & Handle** | Округлое дно + ручка (бычий) |
| **Rectangle** | Горизонтальная консолидация |
| **Measured Move** | Движение = откат = равное движение |

## 5.3 Volume Profile паттерны

- **POC** — уровень максимального объёма (равновесие)
- **Value Area** — 68.2% объёма (VAH/VAL)
- **HVN** — поддержка/сопротивление
- **LVN** — «открытое шоссе»
- **Triple Threat** — HVN + S/R + Anchored VWAP
