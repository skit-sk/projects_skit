# 14_ExpImpUPBP — Выгрузка УП → Загрузка БП

**Назначение:** внешняя обработка (.epf) для выгрузки данных из конфигурации
**«Управление производством» (УП)** и загрузки в **«Бухгалтерию предприятия» (БП) 3.0**.

## Обмен данными

| Направление | Сущности | Формат |
|------------|----------|--------|
| УП → XML   | Номенклатура, Контрагенты, Документы | XML |
| XML → БП   | Номенклатура, Контрагенты, Документы | XML |

## Структура

```
14_ExpImpUPBP/
├── _work/src/                       # XML-исходники (нативный формат 1С)
│   ├── ВыгрузкаЗагрузкаУПБП.xml     # Корневой метаданных ExternalDataProcessor
│   └── ВыгрузкаЗагрузкаУПБП/
│       ├── Ext/
│       │   └── ObjectModule.bsl     # Модуль объекта
│       └── Forms/Форма/
│           ├── Форма.xml            # Метаданные формы
│           └── Ext/
│               ├── Form.xml         # Описание формы (элементы, реквизиты, команды)
│               └── Form/
│                   └── Module.bsl   # Модуль формы
├── scripts/
│   └── build_epf.bat               # Windows-скрипт сборки
├── output/                          # Готовые .epf
├── docs/
└── README.md
```

## Сборка на Windows

1. Откройте `scripts/build_epf.bat` и укажите путь к платформе 1С:

```bat
set V8_PATH=C:\Program Files\1cv8\8.3.24.1667\bin\1cv8.exe
```

2. Запустите `scripts/build_epf.bat` из корня проекта.

Скрипт выполнит:

```
1cv8.exe DESIGNER /BuildEPF _work\src\ВыгрузкаЗагрузкаУПБП.xml /Out output\ВыгрузкаЗагрузкаУПБП_v1.00.epf
```
