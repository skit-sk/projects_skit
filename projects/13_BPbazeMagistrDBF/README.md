# 12_BPbazeMagistrDBF — Загрузчик DBF Магистр → БП 3.0

Внешняя обработка (`ЗагрузкаМагистрDBF.epf`) для загрузки данных из DBF-файлов системы «Магистр» в типовую конфигурацию **«Бухгалтерия предприятия (базовая), редакция 3.0»**.

## Состав

```
12_BPbazeMagistrDBF/
├── output/
│   └── ЗагрузкаМагистрDBF.epf      # Готовая внешняя обработка
├── build/
│   └── src/                         # Исходники в формате v8unpack (JSON)
│       ├── ExternalDataProcessor.json
│       ├── ExternalDataProcessor.obj.bsl
│       └── Form/Форма/
│           ├── Form.json
│           ├── Form.elem.json
│           ├── Form.id.json
│           └── Form.obj.bsl         # Модуль формы (основная логика)
├── _orig_ext/                       # Оригинальное расширение (.cfe) в формате XML
└── _orig_cfe_v8unpack/              # Расширение, распакованное v8unpack (эталон)
```

## Функциональность

1. **Чтение DBF** — XBase, поля: TIOP, NOMD, DATD, KKOD, KNAZV, INN, TKOD, TNAZV, CPOS/SPOS, CPRO/SPRO, NDS10/NDS22 и др.
2. **Разделение на Приход/Расход** по содержанию слова «ПРИХОД» в TIOP
3. **Проверка дублей** — поиск существующих контрагентов (по ИНН/наименованию) и номенклатуры (по артикулу)
4. **Создание справочников**:
   - Контрагенты (ИНН, КПП, ЮЛ/ИП, банковские счета)
   - Номенклатура (артикул, вид «Товары», единицы измерения, НДС)
5. **Создание документов**:
   - `ПоступлениеТоваровУслуг` (вид операции «Товары»)
   - `РеализацияТоваровУслуг` (вид операции «Товары»)
6. **Автоматическое заполнение**: договоры, валюты, счета учёта, НДС, субконто

## Сборка

```bash
source venv/bin/activate
v8unpack -B build/src output/ЗагрузкаМагистрDBF.epf
```

Проверка:
```bash
v8unpack -E output/ЗагрузкаМагистрDBF.epf /tmp/check
```

## Исправления относительно исходного расширения

| # | Изменение | Описание |
|---|-----------|----------|
| 1 | Конвертация .cfe → .epf | Расширение переделано во внешнюю обработку |
| 2 | Маппинг НДС 22% | `NDS22` теперь маппится на `СтавкиНДС.НДС22` (вместо `НДС20`) |
| 3 | Маппинг ВидыСтавокНДС | Добавлен маппинг 22% → «Общая» для карточки номенклатуры |
| 4 | Поиск банка | Исправлен с `СВИФТБИК` на `Код` (в метаданных поле Код = БИК) |
| 5 | Чистка кода | Удалены 3 старые закомментированные функции, 2 блока субконто, мёртвый код |
