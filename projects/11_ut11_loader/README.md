## Ключевые находки

1. **Формат XML совместим** между epf1 и epf2 (для номенклатуры/остатков).
2. **Контрагентов в XML нет** (в исходной выгрузке) — но `v1.04` теперь их выгружает.
3. **У типов цен был пустой `Код`** — исправлено в `v1.04`, теперь пишется.
4. **7 кодов цен в XML**, epf2 v1.72 распознаёт только 1.
   `v1.74` распознаёт все 7 + 3 стандартных = 10 кодов.
5. **20 837 SKU + 685 групп** — большая база, лучше грузить по 1 складу.

## Запуск парсера

```bash

python3 _work/parse_stocks.py /path/to/Остатки.xml [_work/STOCKS_REPORT.md]
```

## Сборка epf из исходников (после правок)

```bash
source /home/user_aioc/workspace/venv/bin/activate
# 1. Скопировать распакованный epf2_src в build/
cp -r /tmp/opencode/ut11_work/epf2_src build/

# 2. Внести правки в build/Form/Форма/Form.obj.bsl
# (см. EPF_V014_STRUCTURE.md)

# 3. Собрать
v8unpack -B build ЗагрузкаДанныхИзXML_V014_UT11.epf
```
