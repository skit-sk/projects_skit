# Инструкция по переносу остатков УТ 10.3 → УТ 11.5 (оптовик)

## Входные данные

- **Источник:** УТ 10.3 + обработка `ВнешняяОбработка10_3v103.epf`
- **Приёмник:** УТ 11.5 + обработка `ЗагрузкаДанныхИзXML_V013.epf` (или v1.74)
- **Файл данных:** `Остатки_20-05-2026_13-02-08-xml.xml` (20 МБ, 21 522 записей)
- **Объём переноса:** остатки + справочники + контрагенты

## Шаг 1. Выгрузка из УТ 10.3

1. Открыть УТ 10.3 → Файл → Открыть → `ВнешняяОбработка10_3v103.epf`
2. Указать:
   - **Дата остатков:** 20.05.2026 (или другая актуальная)
   - **Организация:** выбрать свою организацию
   - **Склад:** выбрать «Склад Курочкин» (затем повторить для «Склад Цыганкова»)
3. Нажать **«Выгрузить в XML»**
4. Сохранить в файл `Остатки_2026-05-20_Курочкин.xml`
5. Повторить для второго склада → `Остатки_2026-05-20_Цыганкова.xml`

> ⚠️ В текущей версии epf1 **в `Справочник_ТипыЦен` не заполняется атрибут `Код`**.
> Если загрузчик этого требует — исправить epf1 (см. `EPF_V014_STRUCTURE.md`).

## Шаг 2. Подготовка УТ 11.5

1. Создать **организацию** с тем же ИНН/КПП, что и в УТ 10.3
2. Создать **склады**:
   - Склад Курочкин (Тип: Оптовый)
   - Склад Цыганкова (Тип: Оптовый)
3. Создать **виды цен** (если их ещё нет в УТ 11):

| Наименование в УТ 11 | Способ задания | Цена вкл. НДС |
|----------------------|----------------|---------------|
| Закупочная | Вручную | Да |
| 1 Оптовая | Вручную | Да |
| 2 Монтажники | Вручную | Да |
| 3 Колонка | Вручную | Да |
| 4 Колонка | Вручную | Да |
| 5 Розничная | Вручную | Да |
| Закупочная+5 | Вручную | Да |
| Розничная +10% | Вручную | Да |

4. Создать **виды номенклатуры**:
   - Товар (без характеристик, без серий)
5. Настроить **учётную политику**:
   - Складской учёт: по складам
   - Партионный учёт: средняя себестоимость (если хотим перенести
     партионные цены; иначе — отключить и заполнять только регистр
     `ТоварыНаСкладахОстатки`)

## Шаг 3. Загрузка в УТ 11.5

1. Открыть УТ 11.5 → Файл → Открыть → `ЗагрузкаДанныхИзXML_V013.epf`
2. Указать:
   - **Путь к файлу:** `Остатки_2026-05-20_Курочкин.xml`
   - **Организация:** выбрать свою
   - **Склад:** Склад Курочкин
3. Нажать **«Загрузить данные»** — должен появиться отчёт со статистикой
4. Проверить, что в таблице появились записи
5. Нажать **«Создать номенклатуру»** — будут созданы элементы
6. Нажать **«Создать ввод остатков»** — будет создан документ
7. Нажать **«Создать установку цен»** — будет создан документ
8. Повторить для второго файла (`..._Цыганкова.xml`)

## Шаг 4. Сверка

После загрузки выполнить **отчёты**:

| Отчёт | Что смотреть |
|-------|--------------|
| «Остатки товаров» (УТ 11) | Сумма остатков = **8 102 840,52** (по каждому складу) |
| «Стоимость товаров» | Общая себестоимость ≈ **521 467 674,04 ₽** |
| «Цены номенклатуры» (по виду цены) | Совпадают ли цены с выгрузкой |
| «Карточка номенклатуры» (выборочно) | Штрих-коды, ед.изм., ставка НДС |

## Известные проблемы

| # | Проблема | Обходное решение |
|---|----------|------------------|
| 1 | В XML нет `Код` у типов цен | Дописать epf1 (см. `EPF_V014_STRUCTURE.md`) |
| 2 | epf2 не создаёт виды цен «1 Оптовая», «2 Монтажники» и т.д. | Создать вручную (Шаг 2.3) или доработать epf2 |
| 3 | В XML нет контрагентов | Переносить отдельной обработкой |
| 4 | Нестандартные ед.изм. («УП.100 шт.») | Создавать как упаковки номенклатуры |
| 5 | Большой объём (20 КБ SKU) — долгая загрузка | Загружать по 1 складу за раз |
