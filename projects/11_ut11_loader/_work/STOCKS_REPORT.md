⚠️ В XML **нет тегов с именами `Цена_Закупочные` / `Цена_Опт1` / `Цена_Розница`** —
есть только динамические коды (`000000001`…`000000003` и `УТ0000001`…`УТ0000005`).
Загрузчик `ЗагрузкаДанныхИзXML_V013.epf` понимает динамические коды (v1.62),
но **только для предопределённого списка: 000000001/000000004/000000005** —
все остальные коды будут проигнорированы.

## Проблемы, требующие решения до переноса

1. **Контрагентов в XML нет** — заявленный в плане перенос контрагентов
   нужно выполнять из другой выгрузки (или вручную).
2. **Коды типов цен в XML пустые** — `ЗагрузкаДанныхИзXML_V013.epf` не сможет
   распознать «1 Оптовая», «2 Монтажники», «3/4 Колонка», «Закупочная+5»,
   «Розничная +10%» как отдельные виды цен. Они сольются в «Оптовая / Розничная».
3. **Формат тегов цен** — 7 уникальных кодов, из них только один
   (`000000001` = «Закупочная») совпадает с логикой epf2.
   Остальные 6 кодов нужна пользовательская таблица соответствий.
4. **Группы 685** — большая иерархия. Перед загрузкой убедиться, что
   УТ 11 выдержит такой объём за один документ «Ввод начальных остатков»
   (epf2 бьёт на части, но лучше перепроверить).
