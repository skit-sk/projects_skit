# Структура адаптированного `.epf` под УТ 11.5

**Целевое имя:** `ЗагрузкаДанныхИзXML_V014_UT11.epf` (v1.73)
**Платформа:** 1С:Предприятие 8.3.x, УТ 11.5, управляемые формы
**Назначение:** Загрузка XML остатков из УТ 10.3 → УТ 11 с полным
маппингом сущностей (виды цен, ед.изм., контрагенты, упаковки).

```
epf2_v013 (исходник)     →   epf_v014 (целевой)

                              + СоздатьКонтрагентов()
```

## Изменения в модуле формы

### 1. Расширенный маппинг цен

**Было (epf2 v1.72, строки 2064-2073):**
```1c
Если РодительскийТег = "Цена_Закупочные" ИЛИ РодительскийТег = "Цена_000000001" Тогда
    ТекущиеДанные.Закупочные = ЗначениеЦены;
ИначеЕсли РодительскийТег = "Цена_Опт1" ИЛИ РодительскийТег = "Цена_000000004" Тогда
    ТекущиеДанные.Опт1 = ЗначениеЦены;
ИначеЕсли РодительскийТег = "Цена_Розница" ИЛИ РодительскийТег = "Цена_000000005" Тогда
    ТекущиеДанные.Розница = ЗначениеЦены;
КонецЕсли;
```

**Стало (v1.73):**
```1c
// Таблица соответствий «код XML → имя колонки ТЗ»
СоответствиеЦен = Новый Соответствие;
СоответствиеЦен.Вставить("000000001", "Закупочные");
СоответствиеЦен.Вставить("000000002", "Опт1");
СоответствиеЦен.Вставить("000000003", "Монтажники");
СоответствиеЦен.Вставить("УТ0000001", "Колонка3");
СоответствиеЦен.Вставить("УТ0000002", "Колонка4");
СоответствиеЦен.Вставить("УТ0000003", "Розничная5");
СоответствиеЦен.Вставить("УТ0000005", "РозничнаяПлюс10");
СоответствиеЦен.Вставить("Цена_Закупочные", "Закупочные");
СоответствиеЦен.Вставить("Цена_Опт1", "Опт1");
СоответствиеЦен.Вставить("Цена_Розница", "Розница");

// При парсинге
Если СтрНачинаетсяС(РодительскийТег, "Цена_") Тогда
    КодЦены = СтрЗаменить(РодительскийТег, "Цена_", "");
    ИмяКолонки = СоответствиеЦен.Получить(КодЦены);
    Если ИмяКолонки <> Неопределено Тогда
        ТекущиеДанные[ИмяКолонки] = ЗначениеЦены;
    КонецЕсли;
КонецЕсли;
```

### 2. Создание видов цен (после строки 3346)

```1c
&НаСервере

    ВидЦены = Справочники.ВидыЦен.НайтиПоНаименованию(Наименование, Истина);

    НовыйВид.Валюта = Справочники.Валюты.НайтиПоНаименованию("RUB");
    НовыйВид.Записать();

    Возврат НовыйВид.Ссылка;

КонецФункции
```

### 5. Создание контрагентов (если есть в XML)

```1c
&НаСервере
Функция ПолучитьИлиСоздатьКонтрагента(Наименование, ИНН = "")

    Запрос = Новый Запрос;
    Запрос.Текст = "ВЫБРАТЬ Ссылка ИЗ Справочник.Контрагенты ГДЕ Наименование = &Наименование";
    Запрос.УстановитьПараметр("Наименование", Наименование);
    Результат = Запрос.Выполнить();
    Если НЕ Результат.Пустой() Тогда
        Выборка = Результат.Выбрать();
        Выборка.Следующий();
        Возврат Выборка.Ссылка;

    НовыйКонтрагент = Справочники.Контрагенты.СоздатьЭлемент();
    НовыйКонтрагент.Наименование = Наименование;
    НовыйКонтрагент.ИНН = ИНН;
    НовыйКонтрагент.ЮрФизЛицо = Перечисления.ЮрФизЛицо.ЮрЛицо;
    НовыйКонтрагент.Записать();

    Возврат НовыйКонтрагент.Ссылка;

КонецФункции
```

### 6. Сборка `.epf` из исходников

```bash
source /home/user_aioc/workspace/venv/bin/activate
mkdir -p build
cp -r epf2_src/* build/        # копия исходников
# ... правки в build/Form/Форма/Form.obj.bsl ...
v8unpack -B build ЗагрузкаДанныхИзXML_V014_UT11.epf
```

## Зависимости и риски

- **Версия УТ 11**: код рассчитан на 11.5. Для 11.4 нужно проверить
  наличие `Справочник.УпаковкиЕдиницыИзмерения` (добавлен в 11.4.1+).
- **Режим совместимости**: 8.3.16+.
- **Расширения**: не используются, обработка остаётся внешней.
