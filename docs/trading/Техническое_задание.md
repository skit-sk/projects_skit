## 4. Обработка (Processing Pipeline)

### 4.1 Нормализация

```
Вход: сырые данные из Collection Layer
Выход: унифицированный формат

Этапы:
1. Приведение timestamp к UTC ISO8601
2. Валидация (отсутствуют ли null, отрицательные цены/объёмы)
3. Дедупликация по trade_id / time
4. Конвертация валют (quote volume в USD)
5. Присвоение symbol_id (int)
```

### 4.2 Ресемплинг (Timeframe Conversion)

```
Вход: raw ticks (1m или тиковые данные)
Выход: бары указанного таймфрейма

Поддерживаемые TF: 1m, 5m, 15m, 30m, 1h, 4h, 1d
Метод: OHLCV aggregation
  open = first trade price
  high = max(high) за период
  low = min(low) за период
  close = last trade price
  volume = sum(volume) за период
  vwap = Σ(price × volume) / Σ(volume)
```

### 4.3 Индикаторный слой (Indicator Calculation)

Все вычисления по единому триггеру — при завершении нового бара:

```
OnBarClose(bar):
  macd_line = ema(close, 12) - ema(close, 26)
  signal_line = ema(macd_line, 9)
  stoch_k = (close - low_14) / (high_14 - low_14) * 100
  stoch_d = sma(stoch_k, 3)
  bb_mid = sma(close, 20)
  bb_std = stddev(close, 20)
  bb_upper = bb_mid + 2 * bb_std
  bb_lower = bb_mid - 2 * bb_std
  atr = ema(true_range, 14)
  natr = atr / close * 100
  vwap = sum(price*volume, period) / sum(volume, period)
```

### 4.4 Паттерн-распознавание

Последовательность вызовов после индикаторного слоя:

```
1. SMC Detection:
   - Scan для поиска Swing High/Low (pivot points)
   - BOS: compare close vs swing high/low
   - CHoCH: break of last structural pivot
   - MSS: CHoCH + body > 1.5 × ATR(14)
   - OB: last opposite candle before impulse
   - FVG: compare Low[i-2] > High[i] (or inverse)

2. Wyckoff Detection:
   - Identify SC: max volume in downtrend
   - Spring: low < SC_low + close > SC_low
   - SOS: breakout with volume spike

3. Elliott Wave Detection:
   - Find 5-wave impulse structure
   - Validate cardinal rules (2<1, 3 not shortest, 4<1)
   - Detect Expanded Flat: B > 100% A, C ≈ 162% A

4. Order Flow Analysis:
   - Calculate Order Book Imbalance
   - Scan for stacked imbalances (3+ levels > 300%)
   - Iceberg detection: T&S cumulative vol vs DOM static size
   - CVD divergence: price high vs CVD lower high
```

## 5. Вычисление (Computation Engine)

### 5.1 Алгоритмы детекции (полный перечень)

#### 5.1.1 MSS Detection

```python
def detect_mss(swing_low, candles, atr_14):
    displacement_threshold = 1.5 * atr_14
    for candle in candles:
        if candle.close < swing_low.low:
            body_size = abs(candle.close - candle.open)
            if body_size > displacement_threshold:
                return MSS(direction='BEARISH', confirmed=True)
    return MSS(confirmed=False)
```

#### 5.1.2 FVG Detection

```python
def detect_fvg(candles):
    """Bullish FVG: Low[i-2] > High[i]"""
    for i in range(2, len(candles)):
        if candles[i-2].low > candles[i].high:
            fvg_top = candles[i-2].low
            fvg_bot = candles[i].high
            ce = fvg_bot + (fvg_top - fvg_bot) * 0.5
            yield FVG(top=fvg_top, bottom=fvg_bot, ce=ce, direction='BULLISH')
```

#### 5.1.3 Spring (Wyckoff)

```python
def detect_spring(candles, volume, sc_level):
    for c in candles:
        if (c.low < sc_level       # wick below SC
            and c.close > sc_level  # close above SC
            and c.volume < volume * 1.2):  # no excessive volume
            return Spring(detected=True, level=c.low)
    return Spring(detected=False)
```

#### 5.1.4 OTE Zone

```python
def calc_ote(swing_low, swing_high):
    range_ = swing_high - swing_low
    return {
        '62%': swing_low + range_ * (1 - 0.62),
        '79%': swing_low + range_ * (1 - 0.79),
        'sweet_spot': swing_low + range_ * (1 - 0.705)
    }
```

#### 5.1.5 Liquidation Price

```python
def calc_lp(entry, leverage, side):
    if side == 'LONG':
        return entry * (1 - 1/leverage)
    else:  # SHORT
        return entry * (1 + 1/leverage)
```

#### 5.1.6 Expanded Flat (Elliott)

```python
def detect_expanded_flat(wave_a, wave_b, wave_c):
    ratio_b = wave_b / wave_a
    ratio_c = wave_c / wave_a
    return (1.05 <= ratio_b <= 1.38 and ratio_c >= 1.62)
```

#### 5.1.7 Iceberg Detection

```python
def detect_iceberg(dom_l2, ts_trades, level, window_sec=30):
    dom_visible = dom_l2.get_size(level)
    ts_volume = sum(t.volume for t in ts_trades
                    if abs(t.price - level) < level * 0.001
                    and t.time > now() - window_sec)
    return ts_volume > 5 * dom_visible
```

#### 5.1.8 OI Trend Health

```python
def oi_trend_health(price_change, oi_change, funding):
    if price_change > 0 and oi_change > 0:
        if abs(funding) < 0.02:
            return 'HEALTHY'
        elif funding > 0.05:
            return 'LEVERAGE_FLUSH'
    if price_change > 0 and oi_change < 0:
        return 'WEAKENING'
    if price_change < -5 and oi_change < -5:
        return 'CAPITULATION'
    return 'NEUTRAL'
```

#### 5.1.9 Dynamic Volume Profile Step

```python
def dynamic_step(atr_14, price):
    step = atr_14 * 0.2
    # Округление до значащих цифр
    decimals = max(0, -int(math.log10(step)) + 1)
    return round(step, decimals)
```

#### 5.1.10 Value Area Calculation

```python
def calc_value_area(volume_profile, total_volume):
    sorted_by_vol = sorted(volume_profile, key=lambda x: -x.volume)
    cum_vol = 0
    va_levels = []
    for level in sorted_by_vol:
        cum_vol += level.volume
        va_levels.append(level)
        if cum_vol >= total_volume * 0.682:
            break
    return ValueArea(
        vah=max(l.price for l in va_levels),
        val=min(l.price for l in va_levels),
        poc=max(va_levels, key=lambda x: x.volume).price
    )
```

### 5.2 Confluence Scoring

```python
def score_entry(results):
    score = 0
    details = {}
    # 1. Wyckoff phase confirmed (A/C/D/E)
    if results.wyckoff.phase in ('C', 'D', 'E'):
        score += 1; details.wyckoff_phase = True
    # 2. MSS confirmed
    if results.smc.mss.confirmed:
        score += 1; details.mss_confirmed = True
    # 3. Liquidity sweep
    if results.smc.breaker_block.exists or results.wyckoff.spring.detected:
        score += 1; details.liquidity_sweep = True
    # 4. Value Area alignment
    if results.volumeProfile.vah >= results.ote.ote_79:
        score += 1; details.value_area = True
    # 5. POI (OB or FVG) exists
    if results.smc.ob or results.smc.fvg:
        score += 1; details.poi = True
    # 6. OTE zone
    if results.ote.current_in_ote:
        score += 1; details.ote = True
    # 7. Liquidation heatmap nearby
    if results.derivatives.nearest_lp:
        score += 1; details.heatmap = True
    # 8. OI healthy
    if results.derivatives.trend_health == 'HEALTHY':
        score += 1; details.oi_healthy = True
    # 9. Footprint confirmation
    if results.orderFlow.stacked_imbalance.detected:
        score += 1; details.footprint = True
    # 10. Risk/Reward check
    if results.rr >= 2.0:
        score += 1; details.rr_ok = True

    return Score(total=score, details=details, valid=(score >= 4))
```

### 7.2 Scoring Engine

```python
def run_analysis(symbol, tf='1h'):
    # 1. Fetch data
    bars = get_ohlcv(symbol, tf, limit=200)
    dom = get_dom(symbol)
    deriv = get_derivatives(symbol)
    onchain = get_onchain(symbol)
    sentiment = get_sentiment()

    # 2. Calculate indicators
    macd = calc_macd(bars)
    atr = calc_atr(bars, 14)
    bb = calc_bollinger(bars, 20, 2)

    # 3. Detect patterns
    swings = find_swing_points(bars)
    smc = detect_smc(bars, swings, atr)
    wyckoff = detect_wyckoff(bars, volume)
    ote = calc_ote(swings[-2], swings[-1])
    vp = calc_volume_profile(bars, atr)

    # 4. Order Flow
    of = analyze_orderflow(dom, trades, bars)

    # 5. Derivatives
    oi_health = oi_trend_health(deriv)

    # 6. Combine => AnalysisResult
    result = AnalysisResult(
        smc=smc, wyckoff=wyckoff, ote=ote,
        volumeProfile=vp, orderFlow=of,
        derivatives=oi_health, onChain=onchain,
        sentiment=sentiment
    )
    result.score = score_entry(result)
    return result
```

### 7.3 Backtesting Module

```python
def backtest(symbol, tf, params, start, end):
    bars = get_historical(symbol, tf, start, end)
    trades = []

    for i in range(200, len(bars)):
        window = bars[:i]
        analysis = run_analysis(window)

        if analysis.score.valid:
            entry_price = bars[i].close
            sl = entry_price - 1.5 * atr  # 1.5 ATR stop
            tp = entry_price + 2 * (entry_price - sl)  # 1:2

            # Simulate trade
            trades.append(Trade(
                entry_time=bars[i].time,
                entry_price=entry_price,
                sl=sl, tp=tp,
                score=analysis.score.total,
                exit_time=None, exit_price=None,
                result=None
            ))

    return backtest_report(trades)
```

## Приложение A: Полный список формул

```
A1.  MACD Line = EMA₁₂(C) − EMA₂₆(C)
A2.  Signal Line = EMA₉(MACD Line)
A3.  Stochastic %K = ((C − L₁₄) / (H₁₄ − L₁₄)) × 100
A4.  Stochastic %D = SMA₃(%K)
A5.  Bollinger Middle = SMA₂₀(C)
A6.  Bollinger Upper = SMA₂₀(C) + 2σ
A7.  Bollinger Lower = SMA₂₀(C) − 2σ
A8.  VWAP = Σ(Pᵢ × Vᵢ) / ΣVᵢ
A9.  True Range = max(H−L, |H−Cₚ|, |L−Cₚ|)
A10. ATR(14) = EMA₁₄(TR)
A11. Normalized ATR = ATR(14) / Close × 100
A12. Chaikin Vol = ((EMA₁₀(HL) − EMA₁₀(HL)₋₁) / EMA₁₀(HL)₋₁) × 100
A13. Historical Vol = σ(ln(Cᵢ/Cᵢ₋₁)) × √252
A14. Volatility Ratio = TR / ATR(14)
A15. Displacement Filter = Body_Size > 1.5 × ATR(14)
A16. FVG (Bullish) = Low[i-2] > High[i]
A17. FVG (Bearish) = High[i-2] < Low[i]
A18. CE = FVG_bottom + (FVG_top − FVG_bottom) × 0.5
A19. Spring = Price < SC_Low + Close > SC_Low
A20. MSS = CHoCH + Body > 1.5 × ATR(14)
A21. OTE 62% = SwingLow + Range × (1 − 0.62)
A22. OTE 79% = SwingLow + Range × (1 − 0.79)
A23. Sweet Spot = SwingLow + Range × (1 − 0.705)
A24. Lp (LONG) = Entry × (1 − 1/Leverage)
A25. Lp (SHORT) = Entry × (1 + 1/Leverage)
A26. Expanded Flat B = 105–138% of A
A27. Expanded Flat C = 162% of A
A28. Order Book Imbalance = (BidVol − AskVol) / (BidVol + AskVol)
A29. Aggressive Imbalance = Ask(price) / Bid(price−1) > 3.0
A30. Iceberg = T&S_Vol > 5 × DOM_Vol
A31. CVD = Σ(AskVol − BidVol)
A32. Value Area = sorted(levels_by_volume) → top 68.2% of total
A33. HVN = level.volume > 1.5 × avg_volume
A34. DynamicStep = ATR(14) × 0.2
A35. EQH/EQL = |High[i] − High[i-1]| < 0.0005 × Price
A36. Put/Call Ratio = Put_Volume / Call_Volume
A37. Funding Drag = FundingRate × 3 × Days × Leverage
A38. MVRV = Market_Cap / Realized_Cap
A39. SOPR = Σ(Spent_USD) / Σ(Cost_Basis_USD)
A40. NVT = Network_Cap / Daily_Tx_Volume
A41. Confluence Score = Σ(valid_factors), valid ≥ 4
A42. RSI = 100 − 100 / (1 + avg_gain/avg_loss)
```
