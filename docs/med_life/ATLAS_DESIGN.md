# Концепция «Атласа человека / паспорта состояния пациента»

## 1. Цель

Визуализировать медицинские данные `11_med_life` в виде интерактивного **Атласа человека** — набора карточек жизненных систем, между которыми можно переключаться, изучать анализы, обследования, назначения, динамику показателей и получать сводный **паспорт состояния** пациента.

## 2. Общая композиция экрана

```
┌─────────────────────────────────────────────────────────────┐
│  [Пациент: Симонов А.О., 1984, м]  [Дата обновления]        │
├──────────┬────────────────────────────────────┬─────────────┤
│          │                                    │             │
│  Лента   │     Центральный вьюпорт            │   Правый    │
│  систем  │     (графики / таблицы / карты)    │   таймлайн  │
│  (иконки)│                                    │   + фильтры │
│          │                                    │             │
└──────────┴────────────────────────────────────┴─────────────┘
```

## 3. Жизненные системы

Левая панель содержит SVG-иконки систем. Каждая иконка показывает:
- цветовой статус (зелёный/жёлтый/красный);
- количество активных препаратов;
- точку, если есть недавние события.

### Список систем

1. **Сердечно-сосудистая**
2. **Дыхательная**
3. **Нервная**
4. **Эндокринная**
5. **Опорно-двигательная**
6. **Пищеварительная**
7. **Мочевыделительная**
8. **Иммунная / аллергическая**
9. **Репродуктивная**
10. **Сенсорная** (зрение, слух)
11. **Психоэмоциональная**
12. **Общий обзор** (радар-диаграмма)

## 4. Страница системы

```
┌────────────────────────────────────────────┐
│  [Назад к Атласу]  Нервная система         │
├──────────────┬─────────────────────────────┤
│              │                             │
│  Индикаторы  │  Таблица записей            │
│  (KPI)       │  (осмотры, анализы)         │
│              │                             │
├──────────────┼─────────────────────────────┤
│              │                             │
│  Тренды      │  Препараты / рекомендации   │
│  (Plotly)    │                             │
│              │                             │
└──────────────┴─────────────────────────────┘
```

### Блоки

- **KPI**: последняя оценка, количество записей, активных препаратов, тренд.
- **Таблица записей**: дата, специалист, диагноз, жалобы, объективно.
- **Тренды**: Plotly-график лабораторий/шкал во времени с референсным диапазоном.
- **Препараты**: карточки с дозой, режимом, ценами, adherence.

## 5. Паспорт состояния

| Слой | Данные | Представление |
|------|--------|---------------|
| **Идентификация** | ФИО, пол, год рождения, группа крови, резус | шапка + карточка |
| **Диагнозы** | `diagnosis_primary`, `diagnosis_secondary`, AI-инференс | список с датами |
| **Аллергии** | `allergies` | бейджи риска |
| **Терапия** | prescriptions + self_prescribed | карточки препаратов |
| **Измерения** | lab + subjective + lifestyle | графики и таблицы |
| **События** | event | вертикальный таймлайн |
| **Документы** | PDF/MD отчёты | ссылки на скачивание |

## 6. Визуализации

| Задача | Технология | Пример |
|--------|------------|--------|
| Общее состояние | Plotly radar chart | оси по 11 системам |
| Тренды лабораторий | Plotly line + shape референс | динамика пролактина |
| Субъективные шкалы | Plotly multi-line | настроение, тревога, сон |
| Таймлайн терапии | CSS timeline / Plotly shapes | курсы препаратов |
| Календарь приёма | Plotly heatmap | medication по дням |
| Иконки систем | SVG-спрайт | 12 иконок |

## 7. Radar chart

Пример JSON (`/med-life/api/<patient_id>/radar`):

```json
{
  "systems": [
    {"name": "nervous", "score": 6.5, "label": "medium"},
    {"name": "musculoskeletal", "score": 7.2, "label": "high"},
    {"name": "digestive", "score": 3.0, "label": "low"},
    {"name": "immune", "score": 4.0, "label": "low"},
    {"name": "endocrine", "score": 5.5, "label": "medium"},
    {"name": "sensory", "score": 2.0, "label": "very_low"},
    {"name": "psychological", "score": 6.0, "label": "medium"}
  ]
}
```

## 8. Цветовая шкала риска

| Score | Label | Цвет |
|---|---|---|
| 0–2 | very_low | Красный |
| 2–4 | low | Оранжевый |
| 4–6 | medium | Жёлтый |
| 6–8 | good | Светло-зелёный |
| 8–10 | excellent | Зелёный |

## 9. Accessibility

- Semantic HTML: `<nav>`, `<main>`, `<section>`.
- `aria-label` у иконок систем.
- `aria-live` для динамического обновления графиков.
- `focus-visible` для клавиатурной навигации.
- Контраст текста >= 4.5:1.
